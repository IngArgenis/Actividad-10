# 🛡️ Manejo de Excepciones en Java

Repositorio de la evidencia práctica enfocada en la resiliencia del software mediante el control de errores. El programa es una calculadora por consola que evalúa e intercepta errores de usuario en tiempo de ejecución.

## 🛠️ Conceptos Técnicos Aplicados
- **Estructura `try-catch`:** Bloque principal para encapsular la lógica de entrada de datos y operaciones.
- **Control de Flujo (`switch`):** Selección de operaciones aritméticas a través de caracteres.
- **Lanzamiento de Excepciones (`throw`):**
  - Validación de división por cero mediante `ArithmeticException`.
  - Validación de operadores no reconocidos usando `IllegalArgumentException`.
- **Bloque `finally`:** Implementado para garantizar el cierre seguro de la clase `Scanner`, evitando fugas de memoria independientemente del resultado de la ejecución.
